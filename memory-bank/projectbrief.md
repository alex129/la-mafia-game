# La Mafia Game - Project Brief

## Project Overview

La Mafia Game is a web-based multiplayer game built using modern web technologies. The project appears to be a social deduction game similar to the classic Mafia/Werewolf party game, implemented as a web application.

## Core Requirements

- Multiplayer web-based game platform
- User authentication and session management
- Real-time game state management
- Role-based gameplay mechanics
- Modern, responsive user interface

## Technical Stack

- Frontend Framework: Astro with Vue.js components
- Styling: TailwindCSS
- Backend/Database: Supabase
- Authentication: Supabase Auth
- Email Service: Resend
- AI Integration: OpenAI
- Deployment: Vercel

## Project Goals

1. Create an engaging multiplayer social deduction game
2. Provide a seamless user experience across devices
3. Implement secure authentication and game state management
4. Enable real-time gameplay with minimal latency
5. Support AI-enhanced gameplay features

## Scope

The project encompasses:

- User authentication and profile management
- Game room creation and management
- Real-time gameplay mechanics
- Role assignment and game flow
- Chat and communication features
- Game state persistence
- AI-powered game assistance

## Success Criteria

- Successful multiplayer game sessions
- Responsive and intuitive user interface
- Secure user data and game state management
- Smooth real-time gameplay experience
- Reliable role-based game mechanics
